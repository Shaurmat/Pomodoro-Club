# Концепция и философия проекта

- Сайт:
1. Сайт посвящен исключительно Pomodoro timer.
2. Функционал сайта сам по себе уже определен как минималистичный и интуитивно ясный. Сайт не нужно нагружать лишними элементами.

- Стиль и дизайн:
1. Стиль и дизайн сайта мягкий, минималистичный и современный.
2. Интерфейс и его элементы имеют скругления, все создается без резких углов.
3. Оттенки и цветовая палитра соответствует пастельным оттенкам, при этом не конфликтующих с белой и темным фоном сайта. 
4. Для информативных блоков интерфейса соответствуют невыраженные и неяркие цвета.
5. Для функциональных кнопок используются более выраженные, но при этом не слишком токсичные и яркие цвета.
6. Можно руководствоваться дизайном приложения Duolingo.

- Код:
1. Основной язык проекта - TypeScript
2. Для интерфейса используется React
3. Использовать понятную и логичную архитектуру проекта.
4.  Каждую самостоятельную часть пользовательского интерфейса по возможности выносить в отдельный React-компонент. Вспомогательные функции, вычисления и бизнес-логику не превращать в компоненты без необходимости.
5. Не создавать чрезмерно большие компоненты.
6. Код должен быть чистым, понятным и поддерживаемым.
7. Не использовать тяжелые библиотеки без необходимости.
8. Предпочитать простые решения сложным, если они дают одинаковый результат.
9. Перед реализацией сложной функции Claude должен предложить варианты решения и объяснить их плюсы и минусы.
10. Окончательное решение принимает разработчик.
11. После реализации Claude должен кратко объяснить:
    - что было изменено;
    - какие файлы изменены;
    - почему было принято такое решение;
    - как работает новая часть кода.
12. Не изменять существующий функционал без необходимости.
